## Core conversion flows

1. Home/Catalog → Product detail → Select variant → Ask on WhatsApp → Transition sheet → WhatsApp.
2. Product card → Add to shortlist → Review products → Send shortlist → Transition sheet → WhatsApp.
3. Home/Store → Store details → Directions or Call → optional WhatsApp.

The WhatsApp payload preserves product name, SKU/model, selected variant, product URL and optional inquiry ID. The website does not take payment.

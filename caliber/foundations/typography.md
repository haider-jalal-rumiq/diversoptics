# Typography

**Instrument Sans** carries display and body. Geometric, precise, readable at small sizes — suitable for model names, specs, and boutique UI.

## Scale

| Role | Size | Weight | Notes |
|------|------|--------|-------|
| Display / H1 | 56px | 700 | Campaign headlines |
| Heading / H2 | 36px | 600 | Section titles |
| H3 | 24px | 600 | Cards / features |
| Body / P1 | 16px | 400 | Long copy |
| P2 | 14px | 400 | UI default |
| Caption / P3 | 12px | 400 | Meta |
| Label / H6 | 11px | 600 | Uppercase tracking |

## Rules

- Use `var(--font-heading)` / `var(--font-body)` — never hardcode the family in components.
- Keep letter-spacing tight on large display; open tracking only on labels.
- Specs tables stay tabular and quiet — no slogan typography in UI chrome.

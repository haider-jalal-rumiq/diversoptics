# Patterns

Industry UI patterns for watch brand sites:

1. **Collection nav** — Collections / Models / Boutiques + Bag
2. **Model card** — watch thumb, reference name, short line, Discover CTA
3. **Movement chips** — Automatic / Manual / Chronograph
4. **Specs table** — case size, movement, water resistance, strap
5. **Discover / enquire CTA** — Champagne primary, ghost secondary
6. **Quiet alert** — stock / boutique appointment feedback

Keep patterns sparse. Prefer one card and one alert over crowded dumps.
